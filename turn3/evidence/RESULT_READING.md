На t=8245 первая смесь дала +0.04526623686072506 бита. Поэтому фраза «pool не допускается» верна только для 7/8 mosaic-миров. Его final shadow=28.365278 не отменяет прежнего admission.

По всем 144 arm-lives минимальный полный префикс -0.990795769328348 бита, максимальная просадка 10.930658342555915 бита — внутри границ −1 и 16. На unrelated все шесть вариантов во всех восьми мирах остались без admission и с нулевым реализованным эффектом. Положительный изменённый хвост отдельных миров означает только фактическую пользу против локального P0 на этих байтах; это не распознавание нового закона целиком.

Среди контролей на изменённых жизнях единственное исключение — pool world35: admission после 8222 байтов, G16384=+3.367961069878523 бита, максимальная просадка10.173356477620107 бита. У остальных global/pool/null вариантов этого режима admission отсутствует и выигрыш равен нулю. Это поздний допуск после смены закона, а не перенос прежнего admission с mosaic-траектории.

## Граница вывода

Получено полезное составление прогноза из двух частично применимых историй при равном объёме прошлого. Один узор может предпочесть A, другой B. Это известное синтетическое семейство с предоставленными границами случаев и точными RGS-координатами. Автоматическое открытие семейств, перенос функций между разными представлениями, естественный язык и кривая обучения после 50 жизней этим PASS не установлены. У каждой строки по-прежнему нет собственного варианта отвергнуть обе книги: такой отказ обеспечивает только общий внешний cold. По завершении независимого reader этот один шаг следует передать дальше; новый опыт здесь не начат.
