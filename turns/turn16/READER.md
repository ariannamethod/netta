## Scope and interpretation

No rate, support threshold, gate or target is selected by this reader. The
repeated suffix support counter is checked as a deterministic update law;
32bits is not treated as an anytime false-alarm guarantee. Empty and harmful
return sets remain in the result. Material FAIL and verification PASS may
coexist.

HEAD256 segmentation and all256 cold probabilities are not recomputed here.
The inherited candidate reader reconstructs role-level probabilities and
checks the retained C full-vector normalization/NEW receipts; the new positive
normalized mixture masses preserve those distributions. This is independent
verification of the new authority organ with the declared inherited boundary.

Output is written only to an unused `--output` path, default `turn16/VERIFY.json`.
No previous source, predictor, archive or result file is changed.
