## What changed in the question

Turn34 asked whether four episode histories pay everywhere. Turn35 asked
whether a fixed source-side subset pays. The retained FAIL separates memory
granularity from memory authority: a source statistic can propose a finer
record, yet recipient evidence must still earn and be able to revoke its
influence. Retuning K on worlds 312–319 would spend the result and is excluded.

The next clean frontier is therefore dynamic and reversible granularity:
start coarse, let source density nominate a fine residual, and let current
evidence allocate or withdraw its bytes and voice under one fixed global
budget. The corresponding control must separate **whether a distinction is
stored** from **whether it currently speaks**.
